# 兩地之間 · Quiet Hours

第一輪可互動美術小樣：巴黎 Three.js 立體光景與台北原創水粉插畫。

執行 `node server.mjs`，開啟 http://localhost:4173 。無建置步驟，依賴已存於 dist/assets。

## 本輪功能
- 巴黎程序生成微縮場景、依真實日期與位置計算日照、影子與晝夜燈光。
- 台北原創圖像、獨立雲層／河面反光／夜色圖層。底圖本身尚未拆成完整前中後景，也未繪製獨立夜景；現階段夜色為程式調色概念。
- 即時雙時區、日期、日出日落、動態時差、位置交換。
- 拖曳巴黎當地時間，同步預覽台北；60 秒一天的光影漫遊；靜態模式及減少動態偏好。
- Live View 為誠實標示的官方來源外連，尚未完成嵌入及授權驗證，不模擬直播。

## 範圍
本輪只有巴黎與台北小樣。其他五城、機場代碼搜尋、地方特色時鐘、正式直播接入待後續迭代。

## 素材
台北插畫由內建 imagegen 生成，prompt 見 ART-DIRECTION.md。巴黎為 Three.js 程序模型，無外部模型。
Three.js 0.180.0 與 SunCalc 2.0.0 採 MIT 授權，授權文件位於 dist/assets。字體為 Google Fonts 的 DM Sans 與 Noto Serif TC，有系統字體備援。
