# 兩地之間 · Quiet Hours

第二輪可互動小樣：台北／巴黎均有 Live View、2D 插畫、3D 動畫三模式，另有一鍵沉浸式屏保頁面。

執行 `node server.mjs`，開啟 http://localhost:4173 。無建置步驟，Three.js 與 SunCalc 依賴已存於 dist/assets。

## 已完成
- 每城市 8 幅獨立時段插畫，共 16 幅；夜景、晨曦、傍晚等均為獨立生成資產。
- 水面遮罩內的逐行微小位移，形成波紋與倒影流動；陸地與建築穩定。不是實際 .gif。
- 每個城市可獨立切換 Live View／2D 插畫／3D 動畫，模式偏好會保存在瀏覽器。
- 巴黎鐵塔、台北101的程序生成微縮模型，隨日期、位置、當前時間改變日照與陰影。
- 當地日期、日出日落、夏令時間時差、兩地交換；任一城市的時間預覽與60秒一天漫遊。
- 八時段圖庫，可點選時段預覽；目前時段時間是可調整的提案，並非原版原封不動的時間表。
- 一鍵沉浸：場景鋪滿、懸掛指針及數字時鐘、拖曳或方向鍵調整時鐘位置、閒置3秒隱藏控制、Esc退出、手機上下雙景。可用時請求瀏覽器原生全螢幕；受限環境保留頁面內滿版。
- 靜態模式、系統減少動態偏好、頁面隱藏時停止繪製。
- Live View 目前為清楚標示的公開來源外連。尚未完成內嵌來源驗證，不假裝直播已在本頁播放。

## 動態與掛鐘修正（2026-11-05）
- 沉浸掛鐘桌面寬上限由350px降至190px，手機112–136px，預設向兩景內側上方移動，增加地標與河面的可見範圍。
- 河水改為更可辨識的局部橫向與縱向波紋，並加入沿水面移動的細碎反光，所有效果限制在水面遮罩內。
- 新增透明前景葉片，台北左上、巴黎右上，以低幅度轉動和位移獨立擺動。
- 雲層改為24–32秒的可見慢速漂移。關閉動態會同時停止河水、葉片及雲層。
- 以1920×1080實際瀏覽器截圖兩幀比較：抽樣建築區域0%變化，水面95.5%、葉片88.8%像素有可辨識變化。這是指定區域的動態驗證，不是整幅圖的變動比例或效能指標。
- 素材格式：網站底圖為JPEG，PNG原圖保留於artwork/originals；葉片PNG使用透明度。水面動畫由Canvas繪製，葉片與雲層由CSS驅動，不依賴圖片檔本身帶動畫。

## 河水舒適度調整（2026-11-05）
- 使用者肯定樹葉，保留現有樹葉效果及雲層漂移。
- 河水主波速度放慢至前版約1/5（巴黎）、1/8（台北）；水平波幅約減半，垂直位移從1.3px降至0.2px（原始圖片座標）。
- 兩城有獨立速度、方向、空間波長、起始相位與反光流速，避免兩邊同步搖擺。

- 修正載入新圖時誤以靜態渲染結束淡入淡出的問題。新圖解碼完成後才開始2.6秒平滑過渡；首張圖直接完整呈現，減少動態模式不強制過渡。

- 新增原創合成輕音樂小樣：巴黎慢鋼琴、台北木質音色。兩者是產品原創聲音設計，並非當地實錄或商業錄音。
- 音樂預設不播放。使用者按播放後才啟用音訊，可選城市、暫停及調音量（降至0即靜音）。
- 每次只連接一座城市的音樂，切換時先淡出並斷開前一首，再啟動下一首；快速連續切換亦不重疊。
- 音樂控制在一般介面和沉浸模式均可使用，沉浸時閒置淡出控制列但可持續聆聽。
